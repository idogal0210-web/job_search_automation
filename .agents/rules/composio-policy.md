# חוק אבטחה: מדיניות שימוש ב-Composio MCP

## Composio MCP Usage Policy
- NEVER invoke or call any `composio` MCP tools autonomously or proactively.
- Use `composio` tools ONLY when explicitly instructed by the user in the current prompt (e.g., "use Composio to...", "השתמש ב-Composio כדי...").
- Before executing any write, send, or modify action via Composio, state the exact action and parameters and wait for explicit user confirmation.
