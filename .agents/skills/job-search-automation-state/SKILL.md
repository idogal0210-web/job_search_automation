# 🧠 Job Search Automation - System State, Brain & Iron Rules

סקיל זה מהווה את **מקור האמת הבלעדי (Single Source of Truth)** לארכיטקטורה, לוגיקת הסינון, ניהול הנתונים והעמידות של מערכת איתור המשרות האוטומטית עבור עידו גל.

---

## 1. מטרת העל והיקף הפרויקט (System Purpose & Scope)
המערכת היא אוטומציה יומית עצמאית (רצה ב-GitHub Actions) שתפקידה לאתר, לסנן ולזקק משרות איכותיות עבור **עידו גל** בשני תחומים מרכזיים:
1. **אנרגיה וגז טבעי:** בקרה תפעולית, גז טבעי, תחנות כוח, מערכות סולאריות PV, מתקני אנרגיה, אחזקה ו-SCADA.
2. **רחפנים וכטב"ם (UAV/Drones):** אינטגרציה, הרכבות, מטיס חוץ/פנים, ניסויי שטח בחברות ביטחון וטכנולוגיה (Percepto, Airobotics, XTEND).

המטרה אינה איסוף כמותי גורף, אלא זיקוק של **עד 5 משרות נבחרות ביום (Top 5)** המדווחות בדשבורד ובאימייל מעוצב.

---

## 2. ארכיטקטורת ייצור נוכחית (Current Production Architecture)
* **קובץ הליבה הפעיל:** `daily_job_search_unified.py` — סורק משרות מלינקדאין (אנרגיה ורחפנים) וממערכת Comeet.
* **תזמון ענן:** רץ ב-GitHub Actions בכל בוקר בשעה 07:17 שעון ישראל (`17 4 * * 0-5`).
* **מעטפת ריפוי אוטונומית (AI Healer):** הריצה ב-GitHub מתבצעת דרך `ai_healer.py` שתופס שגיאות חריגות ומתקן אותן בזמן אמת.
* **מבנה קוד שטוח (Zero Waste & Flatness):** כל מודולי הליבה יושבים ישירות תחת `src/` ללא תתי-תיקיות מיותרות.
* **דשבורד ווב:** נבנה אוטומטית לתוך `docs/index.html` ומוגש דרך GitHub Pages.

---

## 3. חוקי הברזל לסינון והערכה (AI Evaluation & Filtering Rules)
* **פרופיל טכני – הנדסאי מכונות (Practical Engineer):** עידו הוא הנדסאי מכונות (אנרגיה ירוקה וגז טבעי) וחשמלאי מוסמך (בסיום לימודים), **אינו מהנדס B.Sc**. יש לחפש משרות להנדסאי, או משרות הנדסה המביעות גמישות לניסיון מעשי.
* **בונוס שטח וידיים (Hands-on):** העדפה מובהקת לתפקידים הכוללים עבודת שטח, ציוד מכני/חשמלי כבד, אינטגרציה, כיול ובקרה בזמן אמת.
* **רשימה שחורה קשיחה (Strict Blacklist):**
  - חברות מוחרגות ברמת קוד הפייתון במפורש עם ציון התאמה 0: `Raycatch`, `Energean`, `Chevron`, `INGL`.
  - פסילה דטרמיניסטית של משרות מטה/אדמיניסטרציה (HR, כספים, שיווק, מכירות, ניקיון) עוד לפני הפנייה ל-Gemini.
* **רף מעבר לאישור (Thresholds):**
  - משרת רחפנים/כטב"ם: ציון התאמה מינימלי של **70+**.
  - משרת אנרגיה/תפעול: ציון התאמה מינימלי של **60+**.
  - ה-Top 5 נבחרות אך ורק מתוך אלו שעברו את הרף.

## 4. עמידות, אמינות נתונים וחיסכון (Resilience & Data Integrity)
1. **כתיבה אטומית לקבצי נתונים (`state_manager.py`):**
   - לעולם אין לכתוב או לדרוס קובץ JSON ב-`data/` ישירות. חובה להשתמש ב-`state_manager.py` המבצע כתיבה אטומית ומחזיק גיבוי (`.bak`).
2. **סנכרון נתונים מלא ל-Git (The Git Sync Rule):**
   - הקבצים ב-`data/` (`seen_jobs.json`, `rejected_jobs.json`, `weekly_archive.json`) הם זיכרון המערכת.
   - בריצה מקומית חובה לבצע Commit ו-Push ל-`data/` מיד בסיום, כדי למנוע "אמנזיה" בריצת הענן הבאה.
3. **בקרת עלויות וקצב קריאות (API Throttle):**
   - קיימת השהיית `time.sleep(4)` לפני כל קריאה ל-Gemini API למניעת חריגת RPM ב-Free Tier.
   - כל משרה שעברה ניתוח (גם אם נפסלה) נשמרת אוטומטית לקובץ ה-`seen` למניעת בדיקות כפולות.
4. **מנגנון גיבוי חירום (Fallback Keyword Scorer):**
   - במקרה של חסימת API זמנית (`429 RESOURCE_EXHAUSTED`), המערכת אינה קורסת אלא מעבירה משרות רלוונטיות דרך סורק מילות מפתח (SCADA, בקר, סולאר, רחפן) עם ציון 65.
5. **מניעת כפילויות קשיחה (Strict Deduplication):**
   - ניקוי אוטומטי של פרמטרי Tracking מלינקים והצלבת כותרת + שם חברה.
